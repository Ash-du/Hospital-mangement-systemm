# CareCore Hospital Management System

CareCore is a modern hospital management system interface designed to simplify patient operations, scheduling, billing, and clinical visibility.

## Overview

This project presents a polished healthcare platform for hospital administrators, clinicians, and staff. It includes sections for:

- hospital operations overview
- patient and records management
- clinical workflow and scheduling
- billing and finance
- team and leadership overview
- demo request form

## Tech stack

- HTML
- CSS
- JavaScript

## Run locally

Open `index.html` in a browser or serve the project with a local static server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
